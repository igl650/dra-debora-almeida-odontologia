# Imagens do site

Esta pasta contém o retrato profissional e elementos da identidade visual da Dra. Débora Almeida usados no protótipo. O padrão do símbolo substitui, na página inicial, fotografias do consultório que ainda não foram fornecidas.

Antes da publicação oficial, confirme com a profissional a autorização de uso das imagens e obtenha fotos reais do espaço caso a seção visual do consultório seja ampliada. Não represente imagens geradas por IA como fotos do consultório.
